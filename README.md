# Page View Time Series Visualizer

freeCodeCamp — Data Analysis with Python Certification project.

Uses Pandas, Matplotlib and Seaborn to visualize daily freeCodeCamp forum page-view data (2016-05-09 to 2019-12-03) as a line plot, a monthly bar plot, and yearly/monthly box plots.

## Files

- `time_series_visualizer.py` — main solution (`draw_line_plot`, `draw_bar_plot`, `draw_box_plot`)
- `fcc-forum-pageviews.csv` — dataset
- `test_module.py` — unit tests
- `main.py` — runs the visualizations

## Usage

```bash
pip install -r requirements.txt
python main.py
```
